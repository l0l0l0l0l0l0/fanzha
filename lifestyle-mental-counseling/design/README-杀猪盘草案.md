# 杀猪盘反诈游戏 · 草案说明

本目录是「反诈游戏」杀猪盘（网恋 + 虚假投资）品类的设计草案，目的是**让玩家代入受害者心智、照见自己身上的易被诈心理**，把反诈宣传从「说教」变成「中招后的自我觉察」。

## 文件清单

| 文件 | 用途 |
|---|---|
| `受害者心理模型-杀猪盘.md` | 受害者心智的结构化角色卡模板 + 一个完整示例（林姐） |
| `受骗复盘debrief-杀猪盘.md` | 玩家中招后的「复盘界面」文案，含 CBT 思维记录 + 三透镜复盘 + 防御锦囊 |

## 心理框架来源映射（为什么借鉴那套心理咨询技能）

本草案借的是**内容/设计层面的心理框架**，不是把 LLM 治疗管线塞进游戏：

- **CBT 思维记录（事件→想法→感受→行为→反思）** → 见 `受骗复盘debrief` 的「思维记录表」。作用是让玩家复盘「我当时脑子里闪过哪句话、什么情绪推着我转了账」。
- **熵 / 关系模型（认知熵 / 行为熵 / 意义熵 + 交叉熵 H(p,q) = 期望与现实失配 + 共享密码本 + 关系第二定律）** → 见 `受害者心理模型` 的三层熵曲线。杀猪盘的「养熟→背叛」本质就是：先让交叉熵降到极低（灵魂伴侣感），再以密码本崩塌、交叉熵暴涨收场。
- **therapy-board 多流派议会** → 见 `受骗复盘debrief` 的「三透镜复盘」。原技能是 8 位大师会诊，这里收敛为 3 个教育透镜（CBT / 行为经济学 / 叙事），给玩家多视角解释「你为什么信了」。

## 伦理红线（必须在实现时守住）

1. **不真骗**：游戏模拟的是「已被拆解的套路」，绝不能让玩家在不知情下真实损失（含虚拟货币也需明确是模拟）。
2. **知情同意 + 内容警示**：进入杀猪盘关卡前，明示「本关模拟情感诈骗，可能引发情绪不适，可随时退出」；对曾经历类似创伤的玩家提供跳过通道。
3. **目标是免疫，不是再创伤**：复盘的焦点是「识别套路、建立边界」，不是强化羞耻。文案用「任何人处在那个状态都可能中招」替代「你太傻了」。
4. **提供出口**：复盘结尾给出真实求助/举报渠道（反诈专线 96110、国家反诈中心 App）。

# 刷单返利反诈游戏 · 草案说明

本目录是「反诈游戏」刷单返利（虚假兼职 / 垫付返利）品类的设计草案，目的同样是**让玩家代入受害者心智、照见自己身上的易被诈心理**——但和杀猪盘不同，刷单的钩子不是「被爱」，而是「动动手指就能赚」的**轻易获利 + 从众**。

## 文件清单

| 文件 | 用途 |
|---|---|
| `受害者心理模型-刷单返利.md` | 受害者心智的结构化角色卡模板 + 一个完整示例（小芸） |
| `受骗复盘debrief-刷单返利.md` | 玩家中招后的「复盘界面」文案，含 CBT 思维记录 + 三透镜复盘 + 防御锦囊 |

## 心理框架来源映射

与杀猪盘草案共用同一套从心理咨询技能借来的框架，落点不同：

- **CBT 思维记录（事件→想法→感受→行为→反思）** → `受骗复盘debrief` 的「思维记录表」。刷单的核心扭曲是**控制错觉**（「这又不是投资，就是点几下」）与**锚定**（首单真返现 = 它是真的）。
- **熵 / 关系模型（交叉熵 H(p,q) = 期望与现实失配）** → `受害者心理模型` 的熵曲线。这里「关系」是受害者与「平台/导师」的信任：首单返现让 `p ≈ q`（「它真的付钱」），交叉熵极低；后续「垫资解冻」使行为熵↑、q 被揭穿、交叉熵暴涨。
- **therapy-board 多流派议会** → `受骗复盘debrief` 的「三透镜复盘」：CBT / 行为经济学（变动奖励+沉没成本）/ 社会认同（群托从众）。

## 伦理红线（必须在实现时守住）

1. **不真骗**：模拟套路，绝不让玩家真实损失（含虚拟币也明示为模拟）。刷单常瞄准**学生、待业、宝妈**等抗风险弱的群体，模拟更要克制。
2. **知情同意 + 内容警示**：进入关卡前明示「本关模拟兼职诈骗」，提供跳过通道；年轻玩家群体对「赚钱」话题易感，警示要更醒目。
3. **目标是免疫，不是再创伤**：用「任何人处在那个状态都可能中招」替代羞辱；可点出「想补贴家用/攒钱」本身是正当需求，错的是利用它的骗局。
4. **提供出口**：结尾给出真实渠道（反诈专线 96110、国家反诈中心 App），并提示「刷单本身违法，正规兼职不会要你先垫钱」。

# 受害者心理模型（养老诈骗）· 角色卡模板

> 用途：把「受害者为什么会中招」结构化成一张可填写、可复用的角色卡。本类的钩子是**亲情缺口 + 健康/养老焦虑 + 权威信任**，设计时要让玩家先尝到「被人当回事」的暖，再用复盘照见——你捧着的「干儿女」，盯的是你的钱和房。

## 一、角色卡字段（模板）

### 1. 原型标签
- 人口/处境：空巢、独居、丧偶、数字素养弱、怕拖累儿女者；对「白大褂/专家/官方背书」天然信任。
- 一句话人设：玩家要在本关「成为」的这个人。

### 2. 需求空白（Needs Gap）
本类受害者不是贪，是被「空」拿住：
- **亲情空白**：空巢、儿女忙，渴望被惦记、被需要；怕麻烦子女。
- **健康空白**：怕病、怕拖累、想「养生」自己扛。
- **保障空白**：怕养老钱不够、想稳妥增值，给儿女减负。
- **尊严空白**：想被当回事、有面子。
> 设计要点：先让玩家体验「有人每周来看我、叫我爸妈」的暖，**情感替代**在此接管理性。

### 3. 被利用的认知偏差（Cognitive Biases）
- **情感推理**：「他比我亲儿女还亲，不会害我」。
- **权威/专家偏见**：白大褂、「教授」、「药监局认证」（伪造）不可质疑。
- **确认偏误**：只记得「张姨吃了好多了」的见证，忽略无效案例。
- **锚定**：先送鸡蛋/免费体检建立「他们是好人」的锚。
- **沉没成本 / 顺从**：已买一堆，继续买「疗程才有效」。
- **损失厌恶 / 稀缺**：「今天不办就错过名额 / 健康机会」。
- **隐瞒倾向**：怕儿女担心或说自己傻，出事也不声张 → 反复受害。
> 对应骗子手法：拟亲情（干儿子/干女儿每日关怀）、权威伪装（假专家讲座）、社会认同（托儿见证）、稀缺催促、 escalation（保健品→高息养老→以房养老）。

### 4. 情绪状态曲线（按阶段）
| 阶段 | 玩家情绪 | 演出提示 |
|---|---|---|
| 初遇（免费讲座/街头关怀） | 意外温暖、被重视 | 暖色、家常感 |
| 持续关怀（干儿女） | 依赖、填补孤独 | 慢节奏、陪伴感 |
| 推介产品/项目 | 信任 + 一丝疑虑被安抚 | 专家背书演出 |
| 首购（保健品/小额） | 安心、「对身体好」 | 正向反馈 |
| 复购/加码 | 投入加深、自我说服 | 渐进加压 |
| 发现无效/无法兑付 | 困惑、不愿信 | 冷调 |
| 子女发现/崩盘 | 羞耻、自责、想隐瞒 | 留白、压抑 |
| 醒悟 | 「他们要的不是我，是钱和房」 | 释然 + 硬知识 |

### 5. 三层熵曲线（认知熵 / 行为熵 / 意义熵）
借鉴 `entropy-intimate-therapy` 的关系熵模型，把「关怀→收割」画成曲线：

- **认知熵**：对「这人/这产品是否真实可信」的不确定性。持续关怀 + 假资质后↓（「错不了，是真心」）。
- **行为熵**：关怀突然绑定消费/房产抵押时的反常度。本应推高警觉，却被「为你好」框架压住。
- **意义熵**：这事「算什么」。前期↓（「我有了孝顺 surrogate / 稳妥养老」），揭示时↑（「哪有什么家人，是猎物」）。

**交叉熵 H(p, q) 主线**（核心隐喻）：
- `q` = 玩家的信念「这是真儿女般的关怀 / 真管用的养生 / 稳妥养老」。
- `p` = 玩家实际经历。
- 养熟期：稳定关怀 + 假背书让 `p ≈ q`，交叉熵极低 → 「比亲儿女还亲」的错觉（拟亲情共享密码本建立）。
- 收割期：要钱/要房本时 q 被揭穿（他们要的是资产）→ 交叉熵暴涨 → 密码本崩塌。
- **关系第二定律**：剥削性质终会浮现——「要房产证那一刻」，熵揭示真相。

### 6. 信任里程碑 & 裂痕
- 里程碑：免费关怀/体检 → 建立「干儿女」 → 首购保健品 → 推介高息养老 → 要房产证/大额转账。
- 裂痕（玩家可**察觉并退出**的教学设计点）：开始推介要花钱的东西、要求瞒着子女、要房产证/签合同、限时催促。

### 7. 可退出转折点（教学设计点）
标注 3–4 个「只要玩家此刻起疑就能止损」的节点，并在节点给轻微提示（系统弹「真儿女/真医生不会催你偷偷转账」「正经事不用瞒孩子」）。

### 8. 复盘触发
到达「崩盘」或玩家主动选择「告知子女 / 找社区核实 / 报警」时，进入 `受骗复盘debrief-养老诈骗.md`。

## 二、示例角色卡：王阿姨（65 岁，空巢退休）

**1. 原型标签**：王阿姨，65 岁，退休教师，老伴去世，女儿在外地。怕给女儿添麻烦，啥事自己扛。

**2. 需求空白**：
- 亲情空白：女儿忙，平时没人陪说话；渴望被惦记。
- 健康空白：有点慢性病，怕拖累女儿，想自己「调理好」。
- 保障空白：攒了点养老钱，想稳稳增值，给女儿减负。
- 尊严空白：想被当回事。

**3. 被利用的认知偏差**：情感推理、权威偏见、确认偏误、锚定（先送鸡蛋）、沉没成本、隐瞒倾向。

**4. 情绪曲线**：意外温暖→依赖→信任被安抚→安心首购→复购自我说服→发现无效→羞耻想隐瞒→醒悟。

**5. 三层熵（摘要）**：
- 养熟期：认知熵↓、意义熵↓（「有了比亲儿女还亲的人」），交叉熵 H(p,q) 极低。
- 收割期：行为熵↑（要钱/要房本），被「为你好」框架压住。
- 揭示期：q 揭穿（他们要的是资产），交叉熵暴涨，密码本崩塌。

**6. 关键转折（可退出点）**：
- 对方开始推介要花钱的产品 → 可退（真关怀不急着卖）。
- 要求瞒着女儿 → 可退（正经事不用瞒孩子）。
- 要房产证/签理财合同 → 系统提示「凡要房本/大额，先找子女或社区」。
- 「今天不办就错过」催促 → 可退。

**7. 复盘金句（给玩家）**：「你不是傻，你是太想被人当回事、又太怕麻烦儿女。他们卖的，正是你这份孤单。」

# 受害者心理模型（冒充公检法）· 角色卡模板

> 用途：把「受害者为什么会中招」结构化成一张可填写、可复用的角色卡。本类的钩子是**恐惧 + 权威服从**，设计时要让玩家先体验「被当成嫌疑人」的慌乱，再用复盘照见——你怕的，正是骗子下的药。

## 一、角色卡字段（模板）

### 1. 原型标签
- 人口/处境：对体制权威天然敬畏者、法律常识薄弱者、怕「摊上事」连累家人者；**中老年人、数字素养偏弱者**高危。
- 一句话人设：玩家要在本关「成为」的这个人。

### 2. 需求空白（Needs Gap）
本类受害者不是贪，而是被「怕」拿住：
- **安全空白**：怕自己/家人惹上官司、留下案底、影响子女。
- **秩序/服从空白**：长期敬畏公权力，接到「办案」本能配合。
- **核实渠道空白**：不熟 110/社区民警，遇事不知找谁确认，只能信电话那头。
> 设计要点：先让玩家体验「我怎么就成嫌疑人了」的眩晕，**权威服从**在此接管理性。

### 3. 被利用的认知偏差（Cognitive Biases）
- **权威偏见**：穿制服/报编号/说法律术语的人 = 不可质疑。
- **灾难化**：「不配合就被抓 / 家属受牵连」。
- **非黑即白**：「不转账自证清白，就是心里有鬼」。
- **孤立效应**：骗子禁你「别声张、别挂电话、去安静处」→ 切断所有现实核对。
- **时间压迫下的认知窄化**：限时决策让批判性思考掉线。
- **责任转移**：「警官说照做就行」→ 把判断权交出去。
> 对应骗子手法：权威伪装（假通缉令/逮捕令/案号）、恐惧威胁（涉案/洗钱）、孤立（保密）、 escalation（先下载/屏幕共享，再转「安全账户」）。

### 4. 情绪状态曲线（按阶段）
| 阶段 | 玩家情绪 | 演出提示 |
|---|---|---|
| 初遇来「案」 | 意外、紧张 | 来电音 + 冷色调 |
| 确认「涉案」 | 恐惧、慌乱 | 心跳音、画面收窄 |
| 被要求保密 | 孤立、不敢声张 | 切断外界联系演出 |
| 配合（下载/同屏） | 顺从、自我说服 | 低沉引导音 |
| 转「安全账户」 | 恐慌但服从 | 倒计时压迫 |
| 失联/拉黑 | 崩溃、羞耻 | 冷场留白 |
| 醒悟 | 「公检法从不设安全账户」 | 释然 + 硬知识 |

### 5. 三层熵曲线（认知熵 / 行为熵 / 意义熵）
借鉴 `entropy-intimate-therapy` 的关系熵模型，把「威慑→收割」画成曲线：

- **认知熵**：对「对方是否真公权力」的不确定性。正常应在接到「转账要求」时↑（起疑）；但恐慌中被强行压低（「警察说的还能有假」）。
- **行为熵**：对方行为不可预测/反常度。真公检法绝不会电话办案、绝不要你转账——这些反常本应推高行为熵、触发警觉；恐慌下却被合理化。
- **意义熵**：这事「算什么」。前期↓（「是合法办案、我在自证清白」），揭示时↑（「哪有什么办案，是勒索」）。

**交叉熵 H(p, q) 主线**（核心隐喻）：
- `q` = 玩家的信念「这是真公权力在办案、我必须配合才能洗清」。
- `p` = 玩家实际经历。
- 威慑期：恐惧让 victim 主动把 `p` 对齐 `q`（服从），交叉熵被压到极低——你「配合」得越顺，q 越牢。
- 揭示期：真实规则「公检法从不设安全账户、从不电话要转账」击穿 q → 交叉熵暴涨 → 密码本（假案卷/保密程序）崩塌。
- **关系第二定律**：控制/剥削性质终会浮现——「安全账户」那一刻，熵揭示真相。

### 6. 信任里程碑 & 裂痕
- 里程碑：接到「案子」→ 被套取个人信息 → 下载屏幕共享 → 被告知「安全账户」→ 转账。
- 裂痕（玩家可**察觉并退出**的教学设计点）：对方禁你联系家人/银行、要求屏幕共享、要求转「安全账户」、说「案子涉密不能挂断」。

### 7. 可退出转折点（教学设计点）
标注 3–4 个「只要玩家此刻起疑就能止损」的节点，并在节点给轻微提示（战友 NPC / 系统弹「真警察不会要你转账」）。可设计一个「挂断→打 110 核实」的胜利分支。

### 8. 复盘触发
到达「崩盘」或玩家主动选择「挂断并核实 / 报警」时，进入 `受骗复盘debrief-冒充公检法.md`。

## 二、示例角色卡：老周（58 岁，退休）

**1. 原型标签**：老周，58 岁，退休，数字素养一般。某天接到「反诈中心」电话，称其身份证涉嫌洗钱，并说「会牵连女儿」。

**2. 需求空白**：
- 安全空白：最怕「留案底、影响女儿前途」。
- 秩序/服从空白：一辈子守规矩，对「公家」天然服从。
- 核实渠道空白：不熟 110/社区民警，慌乱中只信电话那头。

**3. 被利用的认知偏差**：权威偏见、灾难化、孤立效应、时间压迫下的认知窄化。

**4. 情绪曲线**：意外紧张→恐惧慌乱→孤立不敢声张→顺从配合（下载同屏）→恐慌转账→崩溃羞耻→醒悟。

**5. 三层熵（摘要）**：
- 威慑期：认知熵被恐慌压低（「警察还能有假」），交叉熵 H(p,q) 极低。
- 收割期：行为熵本应因「安全账户」飙升，却被恐惧合理化。
- 揭示期：q 被「公检法不设安全账户」击穿，交叉熵暴涨。

**6. 关键转折（可退出点）**：
- 对方说「别告诉家人、去安静处」→ 可退（真警察不禁止你联系家人）。
- 要求下载屏幕共享/远程软件 → 可退（红 flag）。
- 要求转「安全账户」→ 系统提示「公检法绝不会设安全账户，更不会要你转账」。

**7. 复盘金句（给玩家）**：「你不是傻，你是太想做个守法的好人，又太怕连累家人。骗子卖的，正是你这份老实。」

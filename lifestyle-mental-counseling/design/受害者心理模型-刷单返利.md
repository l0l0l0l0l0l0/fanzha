# 受害者心理模型（刷单返利）· 角色卡模板

> 用途：把「受害者为什么会中招」结构化成一张可填写、可复用的角色卡。刷单的钩子不是情感，而是**轻易获利 + 从众 + 控制错觉**，设计时要让玩家先尝到「真的到账了」的甜，再用复盘照见套路。

## 一、角色卡字段（模板）

### 1. 原型标签
- 人口/处境：学生、宝妈、待业/想补贴家用者；对「轻松赚外快」抵抗力低。
- 一句话人设：玩家要在本关「成为」的这个人。

### 2. 需求空白（Needs Gap）
刷单受害者也不是「贪」，而是有个正当却被利用的需求：
- **经济空白**：想攒钱/还债/补贴家用，对「低门槛赚钱」高度易感。
- **掌控感空白**：现实里缺钱、无力，刷单给「我在赚钱」的掌控幻觉。
- **证明空白**：学生想独立、宝妈想贴补，想证明「我能行」。
> 设计要点：先让玩家体验「首单真的返现了」的惊喜，**控制错觉**在此建立。

### 3. 被利用的认知偏差（Cognitive Biases）
- **控制错觉**：「这又不是投资，就是点几下、比上班轻松」——低估风险。
- **锚定**：首单真到账 → 锚定「它是真的」，后续异常都被这个锚压住。
- **确认偏误**：群里全是「今日赚 XXX」的截图，只看得到赢家。
- **沉没成本 / 承诺升级**：「都充到这步了，再补一笔就能提出来」。
- **损失厌恶 / 灾难化**：「不补钱前面的本金就没了」。
- **小数定律 / 赌徒谬误**：连赢几单后觉得「手气在，下一单更大」。
> 对应骗子手法（Cialdini + 行为设计）：社会认同（群托晒单）、权威（仿冒电商/快递平台 UI）、稀缺（任务 10 分钟截止）、互惠（首单让利）。

### 4. 情绪状态曲线（按阶段）
| 阶段 | 玩家情绪 | 演出提示 |
|---|---|---|
| 初遇 | 好奇、轻松 | 明亮、弹窗式爽感 |
| 首单返现 | 惊喜、信任加固 | 到账音效、高光 |
| 连做小额 | 上头、多巴胺 | 连击反馈、节奏加快 |
| 转大额/连单 | 一丝不安、被群友安抚 | 不安用催促话术盖过 |
| 提现被拒 | 焦虑、自我说服 | 系统红字「需补单解冻」 |
| 持续垫资 | 恐慌、赌徒心态 | 孤注一掷的紧张 |
| 崩盘 | 崩溃、羞耻 | 冷场、留白 |

### 5. 三层熵曲线（认知熵 / 行为熵 / 意义熵）
借鉴 `entropy-intimate-therapy` 的关系熵模型，把「诱饵→收割」画成曲线：

- **认知熵**：对「平台是否真实」的不确定性。首单返现后↓（「它真的付钱」），崩盘时↑（「从头到尾是假的」）。
- **行为熵**：平台行为不可预测度。前期「做任务→返现」稳定；转大额后突然要「垫资解冻」，行为熵↑，但被玩家用锚定压住。
- **意义熵**：这段「兼职」算什么。前期↓（「正当副业/我在赚钱」），崩盘时↑（「哪有什么兼职，是局」）。

**交叉熵 H(p, q) 主线**（核心隐喻）：
- `q` = 玩家的信念「这是个能返现的靠谱兼职」+ 首单建立的「它付过钱」证据。
- `p` = 玩家实际经历。
- 诱饵期 `p ≈ q` → 交叉熵极低 → 「真的能赚」的错觉（群聊=共享密码本，导师指令=可预测回报）。
- 收割期 `q` 被揭穿（返现承诺永不兑现）→ 交叉熵暴涨 → 密码本崩塌。
- **关系第二定律**：剥削性质终会浮现——「垫付才能提现」的那一刻，熵揭示了真相。

### 6. 信任里程碑 & 裂痕
- 里程碑：首单返现 / 连做三轮都到账 / 被拉进「内部高佣群」/ 第一次大额任务。
- 裂痕（玩家可**察觉并退出**的教学设计点）：系统提示「需充值升级才能提现」、群友催「赶紧补单解冻」、提现失败要交「保证金/解冻费」。

### 7. 可退出转折点（教学设计点）
标注 3–4 个「只要玩家此刻起疑就能止损」的节点，并在节点给轻微提示（战友 NPC 嘀咕、系统弹「正规兼职不会让你先垫钱」）。

### 8. 复盘触发
到达「崩盘」或玩家主动选择「报警/退出」时，进入 `受骗复盘debrief-刷单返利.md`。

## 二、示例角色卡：小芸（22 岁，大三学生）

**1. 原型标签**：小芸，22 岁，大三，想攒钱买电脑、还花呗。刷手机看到「日结兼职、动动手指」广告。

**2. 需求空白**：
- 经济空白：花呗待还 + 想买电脑，对「低门槛赚钱」极度易感。
- 掌控感空白：生活费靠家里，想「自己赚到钱」证明独立。
- 证明空白：室友做兼职，不想显得自己「什么都不会」。

**3. 被利用的认知偏差**：控制错觉、锚定、确认偏误、沉没成本、损失厌恶。

**4. 情绪曲线**：好奇→惊喜（首单到账 20 元）→上头（连做三轮都返）→不安被安抚→焦虑（提现被拒）→恐慌垫资→崩溃羞耻。

**5. 三层熵（摘要）**：
- 诱饵期：认知熵↓、意义熵↓（「真的能赚」），交叉熵 H(p,q) 极低。
- 收割期：行为熵↑（要垫资解冻），小芸用「前面都到账了」压住不安。
- 崩盘期：q 揭穿，交叉熵暴涨，密码本崩塌。

**6. 关键转折（可退出点）**：
- 首单后弹出「充值 199 升级会员才能继续」→ 可退（正规刷单本就违法，且不会要你充值）。
- 群友催「最后 5 分钟补单解冻」→ 可退（紧迫感是红 flag）。
- 提现失败要交「保证金」→ 系统提示「任何先交钱再返的都是局」。

**7. 复盘金句（给玩家）**：「你不是笨，你是想靠自己赚到钱——这没错。错的是有人把你的上进，做成了收割你的刀。」

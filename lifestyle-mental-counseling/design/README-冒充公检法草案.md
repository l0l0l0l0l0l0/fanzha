# 冒充公检法反诈游戏 · 草案说明

本目录是「反诈游戏」冒充公检法（假警察/检察院/法院/反诈中心）品类的设计草案。与杀猪盘（情感）、刷单（贪利）不同，这类诈骗的钩子是**恐惧 + 权威服从**：用「你涉嫌洗钱/涉案」制造恐慌，再以「配合调查」为名架空你的判断力。

> ⚠️ 本类模拟会诱发**急性恐惧**，是三类里情绪负荷最重的一种。伦理红线（见下）务必从严。

## 心理框架来源映射

- **CBT 思维记录（事件→想法→感受→行为→反思）** → `受骗复盘debrief` 的「思维记录表」。核心扭曲是**权威偏见**（「警察不会骗我」）与**灾难化**（「不配合就抓人」）。
- **熵 / 关系模型（交叉熵 H(p,q) = 期望与现实失配）** → `受害者心理模型` 的熵曲线。这里「关系」是受害者与「假权威/机构」：恐慌下 victim 把经历强行对齐 q（「这是真办案」），交叉熵被恐惧压低；揭示「公检法从不设安全账户」时 q 崩塌、交叉熵暴涨。
- **therapy-board 多流派议会** → `受骗复盘debrief` 的「三透镜复盘」：CBT / 社会心理学（权威服从+孤立切断核实）/ 危机应激（恐惧窄化理性）。

## 伦理红线（本类必须从严）

1. **不真骗、不收信息**：模拟绝不收集玩家真实身份/人脸/验证码；不生成可被误认为真实公文的素材。
2. **知情同意 + 强警示 + 易退出**：进入关卡前显著提示「本关模拟电信诈骗、会引发紧张恐惧，可随时退出」；提供一键跳过。中老年玩家易感，警示最醒目。
3. **目标是免疫，不是恐吓**：复盘把「害怕摊上事」正常化，并指出「怕，恰恰说明你是个守法的普通人」；不羞辱。
4. **给真实出口**：结尾给出 96110、110 及「公检法绝不设安全账户」的硬知识。

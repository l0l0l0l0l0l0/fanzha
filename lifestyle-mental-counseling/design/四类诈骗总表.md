# 四类诈骗 · 角色卡与熵曲线总表

> 用途：合集关卡的「一览表」。四类共用同一套 `VictimCard`（8 字段）+ `EntropyCurve` + `ThoughtRecord` + `LensPanel` 组件，差异只在字段取值。本表把「钩子 / 情绪曲线 / 熵曲线 / 核心认知偏差 / 可退出点 / 防御一句话」横向拉平，方便排期与对比教学。

| 维度 | 杀猪盘 | 刷单返利 | 冒充公检法 | 养老诈骗 |
|---|---|---|---|---|
| **核心钩子** | 被爱 + 被重视 | 轻易获利 + 从众 | 恐惧 + 权威服从 | 亲情缺口 + 健康/养老焦虑 + 权威信任 |
| **需求空白** | 情感/意义/掌控 | 经济/掌控/证明 | 安全/秩序/核实渠道 | 亲情/健康/保障/尊严 |
| **情绪曲线** | 好奇→被理解→上头→自信→焦虑→震惊羞耻 | 好奇→惊喜→上头→不安→焦虑→恐慌→崩溃 | 紧张→恐惧→孤立→顺从→恐慌→崩溃 | 温暖→依赖→信任→安心→复购→羞耻隐瞒 |

## 设计节奏建议（合集关卡）

1. **由轻到重排情绪负荷**：刷单（贪利，最轻）→ 杀猪盘（情感）→ 养老（亲情+隐瞒）→ 公检法（恐惧，最重，需强警示+易退出）。
2. **共享组件复用**：`VictimCard / EntropyCurve / ThoughtRecord / LensPanel` 一套代码四套取值；`ANTI_FRAUD_HOTLINE = "96110"`。
3. **每类一个正向收口分支**：刷单/杀猪盘=识破套路止损；公检法=挂断核实；养老=告知子女（示范支持型陪伴）。
4. **统一伦理底线**：不真骗、不收隐私、知情同意+警示、不羞辱只照见、给真实出口。

# 养老诈骗反诈游戏 · 草案说明

本目录是「反诈游戏」养老诈骗品类的设计草案。与前三类不同，养老诈骗的钩子是**亲情缺口 + 健康/养老焦虑 + 对权威专家的信任**，且受害者多为空巢老人——他们不是贪，是「太想被当回事、太怕拖累儿女」。

> 本类极易因「羞于告知子女」而反复受害。伦理上必须把「告诉儿女不丢人」做成核心正向价值。

## 文件清单

| 文件 | 用途 |
|---|---|
| `受害者心理模型-养老诈骗.md` | 受害者心智的结构化角色卡模板 + 一个完整示例（王阿姨） |
| `受骗复盘debrief-养老诈骗.md` | 玩家中招后的「复盘界面」文案，含 CBT 思维记录 + 三透镜复盘 + 防御锦囊 |

## 心理框架来源映射

- **CBT 思维记录** → `受骗复盘debrief` 的「思维记录表」。核心扭曲是**情感推理**（「他比我亲儿女还亲」）与**权威偏见**（白大褂/「专家」不可质疑）。
- **熵 / 关系模型** → `受害者心理模型` 的熵曲线。这里「关系」是受害者与「假儿女/假专家」的拟亲情：持续关怀 + 伪造资质把交叉熵压低（「真家人/真管用」），揭示「他们要的是钱和房」时 q 崩塌、交叉熵暴涨。
- **therapy-board 多流派议会** → `受骗复盘debrief` 的「三透镜复盘」：CBT / 依恋与孤独（情感替代）/ 权威与信息弱势（专家偏见+难核实）。

## 伦理红线

1. **不真骗、不收隐私**：模拟绝不收集玩家真实健康/房产/子女信息；不生成可被误认的伪公文/伪资质。
2. **知情同意 + 强警示 + 易退出**：进入关卡前提示「本关模拟针对老年人的诈骗」，提供跳过。
3. **目标是免疫，不是羞辱**：把「怕麻烦儿女、想自己扛」正常化；复盘落点是「告诉儿女/社区不丢人」。游戏内可设计一个**支持型子女回应**分支，示范正确陪伴。
4. **给真实出口**：结尾给出 96110、社区民警，及「正规养老政策不私聊推销、不要房产证」的硬知识。

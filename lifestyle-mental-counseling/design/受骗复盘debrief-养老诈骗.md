# 受骗复盘 Debrief（养老诈骗）· 界面文案草案

> 触发：玩家到达「崩盘」或主动选择「告知子女 / 找社区核实 / 报警」后进入。
> 基调：不羞辱、只照见。把「怕麻烦儿女、想自己扛」正常化；落点是「告诉儿女/社区不丢人」。

---

## 屏幕 1：双屏对比（你的故事 vs 真相）

左屏「你以为的」：
> 一个比亲儿女还亲的「干女儿」，每周来看你、陪你说话；一位权威「教授」说这保健品能调好你的身子；一个「国家背书」的养老项目，让养老钱稳稳增值。

右屏「实际上的」：
> 一条冲着你钱和房来的流水线。免费鸡蛋是锚，每日关怀是拟亲情的共享密码本，白大褂是伪造的权威。交叉熵 H(p,q) 从极低（「比亲儿女还亲」）到暴涨：他们要的从来不是你，是你的养老钱和房产证。

> 小字注：你想自己扛、不想麻烦儿女，这没错。错的是有人把你的孤单，做成了收割你的镰刀。

## 屏幕 2：CBT 思维记录表（填空式复盘）

> 引导语：把当时脑子里那句话写下来。下次再有人对你过分热情又急着要钱，你会认得它。

| 字段 | 你当时（示例：王阿姨） |
|---|---|
| **事件** | 「干女儿」推介「以房养老」高息理财，要房产证抵押，说别告诉女儿 |
| **想法** | 「她比我亲女儿还亲，不会害我；这项目正规，不办就错过，也不想麻烦闺女」 |
| **情绪** | 安心 60% + 一丝犹豫被安抚 |
| **行为** | 配合提供房产证信息、准备签约 |
| **更健康的想法（现在填）** | 真儿女/真医生不会催我偷偷签字；正规养老政策不私聊推销、不要房产证；先打给女儿或社区民警 |

玩家填写后，系统高亮命中的认知扭曲：
- 「比亲女儿还亲」→ **情感推理**
- 「教授/正规项目」→ **权威偏见**
- 「不办就错过」→ **损失厌恶 / 稀缺**
- 「不想麻烦闺女」→ **隐瞒倾向（反复受害的温床）**

## 屏幕 3：三透镜复盘（多视角解释你为何信了）

借鉴 `therapy-board` 的「多大师会诊」，收敛为 3 个教育透镜：

**① CBT 透镜（认知行为）**
你被几道扭曲接力带走了：先「情感推理」把关怀当真情，再「权威偏见」把白大褂当真理，最后「损失厌恶 + 隐瞒倾向」让你既掏钱又不声张。越瞒，越被套牢。

**② 依恋与孤独透镜（情感替代）**
空巢的孤单，被「干儿女」精准填上。人在情感空缺时，会把持续的温暖误认为亲情（依恋替代）。识破「关怀→推销」的转化点，是关键：真亲情不急着卖你东西。

**③ 权威与信息弱势透镜（难核实）**
白大褂、「教授」、伪造资质，利用了你对专家的天然信任，也利用了你不便上网核实的信息差。应对硬规则：**凡要房本/大额，先找子女或社区民警核实**——用你自己的渠道。

---

## 屏幕 4：防御锦囊（可带走的 3 条）

1. **天上不会掉儿女**：对你过分热情、又急着让你掏钱的「干儿子/干女儿/专家」，先打问号。真儿女、真医生不会催你偷偷转账或抵押房产。
2. **保健≠治疗**：凡宣称「包治百病 / 替代药物」的保健品一律假；有病去正规医院，别信讲座「神药」。
3. **房本钱袋子守紧**：任何「以房养老 / 高息养老」要你抵押房产或转账的，先和子女、社区民警核实。正规养老政策**不私聊推销、不要房产证**。

> 真实出口：遇可疑情况拨 **96110 / 110**，找社区民警。告诉儿女不丢人——你省下的，是全家的安心。你刚才经历的，是已被拆解的套路——现实里没有「复盘」按钮，先按暂停。

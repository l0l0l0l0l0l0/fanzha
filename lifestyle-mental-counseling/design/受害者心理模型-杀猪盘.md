# 受害者心理模型（杀猪盘）· 角色卡模板

> 用途：把「受害者为什么会中招」结构化成一张可填写、可复用的角色卡。游戏设计时用它驱动**对话分支、情绪演出、可退出转折点**；复盘时用它回放玩家的心理轨迹。

## 一、角色卡字段（模板）

### 1. 原型标签
- 人口/处境关键词：年龄、情感状态、独居/异地、近期生活事件（丧亲、失业、离异、空巢）。
- 一句话人设：玩家要在本关「成为」的这个人。

### 2. 需求空白（Needs Gap）
受害者不是「贪」，而是心里有个洞被骗子精准填上了：
- **情感空白**：孤独、渴望被看见/被重视。
- **意义空白**：想证明自己「还能被爱 / 还能翻盘」。
- **掌控感空白**：现实里失控，想在「投资」里找回掌控。
> 设计要点：先让玩家**体验被填满的甜**，后面背叛才痛。

### 3. 被利用的认知偏差（Cognitive Biases）
列出本关会触发、并在复盘时点名的偏差：
- 情感推理：「我感到被爱，所以是真的。」
- 确认偏误：只记住吻合「灵魂伴侣」的证据，忽略矛盾。
- 理想化 / 光环效应：把温柔关怀泛化为「完美的人」。
- 沉没成本谬误 / 承诺升级：已投的钱和感情让我继续加码。
- 读心术 / 应该思维：「他那么爱我，不会骗我。」
- 损失厌恶 / 灾难化：「错过这波机会就亏大了。」
> 对应骗子手法（Cialdini）：互惠（先分享/小投回本）、喜好（相似+温柔）、权威（投资「导师」）、稀缺（限时名额）、社会认同（群友晒盈利）。

### 4. 情绪状态曲线（按阶段）
| 阶段 | 玩家情绪 | 演出提示 |
|---|---|---|
| 初遇 | 好奇、被关注的新鲜 | 暖色、轻音乐 |
| 养熟 | 被理解、上头 | 慢节奏、私语感 |
| 引投 | 兴奋+一丝不安 | 节奏加快，不安用细微音效 |
| 小赚 | 自信、信任加固 | 高光反馈 |
| 加码 | 焦虑但被「他」安抚 | 安抚话术压过警报 |
| 崩盘 | 震惊、羞耻、空洞 | 冷色、留白 |

### 5. 三层熵曲线（认知熵 / 行为熵 / 意义熵）
借鉴 `entropy-intimate-therapy` 的关系熵模型，把「养熟→背叛」画成一条曲线：

- **认知熵**：对「对方是谁」的不确定性。养熟期↓（「他太懂我了」），崩盘期↑（「我根本不认识他」）。
- **行为熵**：对方行为不可预测度。引投/加码时悄悄↑（要钱与投资话术不符浪漫框架），但被玩家用认知扭曲压住。
- **意义熵**：这段关系「算什么」的模糊度。养熟期↓（「这是真爱/我的逆袭」），崩盘期↑（「从来没有什么爱情」）。

**交叉熵 H(p, q) 主线**（核心隐喻）：
- `q` = 骗子精心塑造的「灵魂伴侣 persona」+ 玩家自己的内部工作模型（IWM，理想伴侣模板）。
- `p` = 玩家实际经历。
- 养熟期 `p ≈ q` → 交叉熵极低 → 「命中注定」的错觉（共享密码本建立、米开朗基罗效应：他让你觉得成了更好的自己）。
- 崩盘期 `q` 被揭穿 ≠ 任何真实的人 → 交叉熵暴涨 → 密码本崩塌。
- **关系第二定律**：不被维护的关系，其真实性质（剥削）终会浮现——熵会揭示真相。

### 6. 信任里程碑 & 裂痕
- 里程碑：第一次深夜聊天 / 第一次「他」主动分享投资 / 第一次一起「赚到」/ 第一次大额转账。
- 裂痕（玩家可在此**察觉并退出**，教学设计点）：话术开始要钱、拒绝视频/见面、盈利无法提现、群友催促。

### 7. 可退出转折点（教学设计点）
标注 3–4 个「只要玩家此刻起疑就能止损」的节点，并在节点给轻微提示（如战友 NPC 的嘀咕、系统弹「感觉不对？」）。

### 8. 复盘触发
到达「崩盘」或玩家主动选择「报警/退出」时，进入 `受骗复盘debrief-杀猪盘.md`。

## 二、示例角色卡：林姐（38 岁，离异独居）

**1. 原型标签**：林姐，38 岁，离异两年，独居，女儿随前夫。白天是会计，晚上刷短视频解闷。

**2. 需求空白**：
- 情感空白：离异后没人再对她说过「辛苦了」，渴望被温柔对待。
- 意义空白：觉得自己「这辈子就这样了」，想证明还值得被爱、还能让生活变好。
- 掌控感空白：工作重复、收入固定，想在「理财」里找回翻盘的掌控感。

**3. 被利用的认知偏差**：情感推理、确认偏误、理想化、沉没成本、损失厌恶。

**4. 情绪曲线**：好奇→被理解→兴奋不安→自信→焦虑被安抚→震惊羞耻。

**5. 三层熵（摘要）**：
- 养熟期：认知熵↓、意义熵↓（「他懂我，这是缘分」），交叉熵 H(p,q) 极低。
- 引投期：行为熵微↑（要钱），但林姐用「他也是为我好」压住。
- 崩盘期：q 揭穿，交叉熵暴涨，密码本崩塌，意义熵拉满。

**6. 关键转折（可退出点）**：
- 他第一次提「一起投个短线」→ 林姐可问「这是什么平台？」
- 他拒绝视频 → 可起疑「真人会不敢见面吗？」
- 盈利提现失败 → 系统提示「正规平台不会卡提现」。

**7. 复盘金句（给玩家）**：「你不是贪，你是太久没被好好对待。他卖的不是理财，是‘被爱’。」

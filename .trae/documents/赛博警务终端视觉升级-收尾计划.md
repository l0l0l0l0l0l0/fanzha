**文件**：`src/scenes/GameShellScene.ts`

**2b. 改 `update(dt)`**（L29-32）

**2c. 改 `renderTopBar`**（L54-108）

在背景填充（L57-61 `fillRect(0,0,screenW,48)` + 分隔线）之后、返回按钮之前，插入 2px 警灯条：

```ts
// 警灯条：左红右蓝交替闪烁（4Hz）
const phase = Math.floor(this.t * 4) % 2 === 0;
ctx.save();
const halfW = screenW / 2;
ctx.fillStyle = phase ? "#E5353B" : "#1B5FCC";
ctx.shadowColor = ctx.fillStyle;
ctx.shadowBlur = 6;
ctx.fillRect(0, 0, halfW, 2);
ctx.fillStyle = phase ? "#1B5FCC" : "#E5353B";
ctx.shadowColor = ctx.fillStyle;
ctx.fillRect(halfW, 0, halfW, 2);
ctx.restore();
```

效果：顶栏最上方 2px 横条，左半红/右半蓝以 4Hz 交替，带 shadowBlur 辉光，营造警车顶灯扫视感。

## 假设与决策

1. **不改玩法逻辑**：仅视觉/动效层，不触碰任何游戏数值、关卡、输入处理。
2. **不回退已完成工作**：Layer 1/2 + Hub/Briefing 已验证稳定，本次只在其上追加。
3. **警灯条用 2px 而非更粗**：避免遮挡顶栏内容（顶栏高 48px，2px 占比 4%，视觉存在感够但不抢戏）。
4. **ResultOverlay 失败 glitch 只触发一次**：用 `lostGlitchDone` 守门，避免每帧重复触发导致画面持续撕裂。
5. **彩屑从屏幕顶部下落**（非从卡片顶部）：让彩屑覆盖全屏更有"庆祝感"，粒子在 `ctx.restore()` 前渲染会叠在面板之上。
6. **构建验证用 `npm run check` + `npm run build`**：前者查类型，后者查打包，二者皆过即视为交付完成。

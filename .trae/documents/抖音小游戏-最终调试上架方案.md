# 抖音小游戏 — 最终调试与上架方案

## 背景与现状

React → 抖音小游戏的迁移已基本完成（40 个 TypeScript 源文件、平台适配层、4 个游戏引擎、9 个场景、esbuild 构建管线、game.js 已生成 160KB）。但经过逐文件审查，发现以下 **3 个阻塞性问题** 会导致项目无法在抖音开发者工具中正常打开/调试：

### 问题 1：appid 无效（阻塞调试）
`project.config.json` 中 `"appid": "tt REPLACE_WITH_YOUR_APPID"` 是占位符，抖音开发者工具无法识别。参考同目录下 `雷霆反诈/project.config.json` 使用 `"touristappid"`（游客模式）即可在开发者工具中本地调试。

### 问题 2：缺少 packOptions.ignore（阻塞调试 + 上架）
项目根目录下存在 3 个参考子项目（`是男人就反诈/`、`雷霆反诈/`、`职业经理人/`）和 `.trae/` 文档目录。没有 `packOptions.ignore` 配置时，抖音开发者工具会尝试将这些目录编译进游戏包，导致：
- 编译报错（参考项目有自己的 game.json/project.config.json，会被误识别为子包）
- 包体膨胀（`职业经理人/` 包含大量 Cocos 资源和 JSON 配置）
- 上架审核被拒（包含无关文件）

### 问题 3：setting 字段不完整
当前 `setting` 缺少 `urlCheck`、`uploadWithSourceMap`、`packNpmManually` 等抖音开发者工具期望的字段，可能导致部分功能异常。

## 假设与决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 本地调试 AppID | `touristappid`（游客模式） | 与参考项目 `雷霆反诈` 一致，无需注册即可调试 |
| packOptions 策略 | 排除所有非游戏文件 | 避免编译错误和包体膨胀 |
| 字体加载 | 保持现状（graceful 降级） | try/catch 已处理缺失文件，系统字体 PingFang SC 足够 |
| 音效方案 | 保持现状（WebAudio 合成） | 无需音频资源文件，体积最小 |
| React 注释清理 | 可选 | 不影响功能，仅为代码整洁 |

## 关键架构约束（已落地，新文件须遵循）

1. **引擎画布固定分辨率**：FraudBuster 480×800、Thunder 540×960（竖屏）；Manager 960×540、BombIsland 960×540（横屏）
2. **触摸路由**：`SceneDirector.dispatchTouch` → `scene.handleTouch` 返回 `true` 则加入 `consumedTouchIds`；引擎 `InputManager` 自监听 `tt.onTouchMove/End`（start 由 Scene 先处理）。`Input.ts` 的 `bind()` 未检查 consumedTouchIds，因此**引擎使用拖拽的场景（Thunder/BombIsland）须在 Scene 层用 consumedTouchIds 拦截按钮区域**
3. **`GameShellScene` 基类**已提供：顶部 HUD（返回/标题/暂停/音效）、底部权威条、退出确认 Modal、暂停覆盖层。子类实现 `getGameTitle/getGameSubtitle/getAccent/updateGame/renderGame/handleGameTouch`
4. **横屏场景**：进入时 `setOrientation("landscape")`，`exit()` 时恢复 `"portrait"`
5. **`platformStore.recordGame()`**：结算时调用一次，记录 gameId/score/busted/durationSec

## 改动清单

### 改动 1：`src/scenes/ResultOverlay.ts`（新建）

**是什么**：结算卡片，作为可组合组件（非 Scene），被各游戏场景持有并在 `render` 末尾绘制。
**为什么**：游戏场景需在引擎画面之上叠加结算卡片，并支持再来一局/返回/分享/下一关。做成组件便于复用。
**怎么做**：
- 导出 `ResultOverlay` 类，构造参数：`director: SceneDirector`、`result: GameResultPayload`、回调 `onRetry/onBack/onNext?/nextLabel?`
- `enter()`：调用 `platformStore.recordGame()`（仅一次，用 `recorded` 标志保护）
- `update(dt)`：维护 `enterT`（0→1 渐入动画）、按钮脉冲计时
- `render(ctx, screenW, screenH)`：
  - `drawModalOverlay` 全屏遮罩
  - 居中面板（`drawPanel`，borderColor = `withAlpha(game.accent, 0.6)`）
  - 标题（胜=绿色 `#52C41A` "战斗胜利" / 负=金色 `#FFD666` "战斗结束"）
  - 2 个 `drawStatCard`：本局得分 + （wave?最高波数 : destroyRate?摧毁率 : 击败数）
  - 反诈锦囊面板（`tip = TIPS.find(result.tipId)`，标题+正文+96110/国家反诈中心 APP 徽章）
  - 按钮组：再来一局(primary) / 下一关(optional primary) / 返回 Hub(ghost) / 分享(ghost icon)
- `handleTouch(type, x, y)`：命中检测各按钮，end 时触发回调；返回 `true` 表示消费（阻止穿透到引擎）
- 分享：调用 `shareAppMessage({ title: "我在《...》中..." })`（替代 clipboard）

### 改动 2：`src/scenes/FraudBusterScene.ts`（新建，继承 GameShellScene）

**是什么**：「是男人就反诈」竖屏游戏场景。
**为什么**：BriefingScene 导入它；引擎 `FraudBusterEngine` 不用 InputManager，按钮判断由 Scene 触摸处理。
**怎么做**：
- `enter()`：创建离屏画布 `director.createOffscreenCanvas()` → `new FraudBusterEngine(canvas)` → `engine.on("toast", ...)` / `engine.on("result", ...)` 缓存 toast/result
- `updateGame(dt)`：引擎已自驱动（GameEngine 主循环），无需额外；但 FraudBusterEngine 继承 GameEngine 自带 rAF，**注意**：GameEngine 自己启动 rAF 循环渲染到离屏画布，Scene 的 `renderGame` 只需 blit
- `renderGame(ctx, screenW, screenH)`：`director.blitContain(engineCanvas, ctx, screenW, screenH)` → 绘制底部双按钮（举报左红 / 通过右绿，各占 45% 宽，高 56，避开底部权威条 24px）→ 绘制 toast → 若 result 存在则绘制 ResultOverlay
- `handleGameTouch`：start 命中举报→置 pressed；end 命中举报→`engine.judge("fraud")`，命中通过→`engine.approvePass()`（注意：引擎方法名实际是 `judge("fraud"|"pass")`，无 `approvePass`，按引擎实际 API 调用）
- 引擎 emit `"result"` 时：创建 `ResultOverlay`，onRetry=重建引擎+新画布，onBack=`director.replace(new HubScene(director))`
- `exit()`：`engine.destroy()`

**按钮布局**（竖屏，y 从底部权威条上方起）：
- 举报：`{ x: screenW*0.04, y: screenH-24-56-12, w: screenW*0.44, h: 56 }`，variant=danger，text="举报" subText="是诈骗"

### 改动 3：`src/scenes/ManagerDeployScene.ts`（新建，继承 Scene）

**是什么**：经理人部署阶段，纯 Canvas UI 无引擎。
**为什么**：BriefingScene 导入它；玩家需先部署 6 探员到 3×3 网格再进入战斗。
**怎么做**：
- 状态：`selectedAgentIdx: number | null`、`slots: DeploySlot[9]`（3×3，初始 agentId=null）
- `render`：背景 + 顶部标题（"反诈职业经理人 · 部署"）+ 6 个探员卡片（横排 2 行×3 列，emoji+名称+角色+ult 描述，选中高亮）+ 3×3 战位网格（已放置显示探员 emoji+HP）+ 敌方情报预览（3 波）+ 底部"开始战斗"按钮（全部 6 探员放置后高亮）
- `handleTouch`：
  - 命中探员卡片 → `selectedAgentIdx = idx`
  - 命中网格 cell：若 selectedAgentIdx != null 且 cell 空 → 放置；若 cell 已有探员 → 撤回（agentId=null）

## 假设与决策

1. **引擎自驱动**：`GameEngine` 基类自带 rAF 循环，`start()` 后自动渲染到离屏画布。Scene 的 `renderGame` 只需 `blitContain`，**不**重复调用引擎 update。
2. **触摸消费约定**：所有 Scene 按钮 `handleTouch` 命中时返回 `true`，使 SceneDirector 加入 consumedTouchIds；引擎 InputManager 的 `bind()` 未检查该 Set（已确认代码），但引擎仅处理**未在 start 阶段被消费的 touch**——因 SceneDirector 对已消费 id 的 move/end 不会传给场景，引擎自身监听 move/end 时需自行判断。**实际验证点**：若发现按钮和拖拽冲突，在引擎 InputManager 的 moveCb/endCb 中增加 `if (director.consumedTouchIds.has(id)) return` 判断。这是收尾阶段重点测试项。
3. **横屏降级**：若 `tt.setOrientation` 不可用（已 try-catch），引擎画布 960×540 会在竖屏 letterbox 显示（上下大黑边），功能不受影响。
4. **字体降级**：`tt.loadFont` 失败时退化为系统字体，不影响功能。
5. **ManagerDeployScene 不继承 GameShellScene**：因无引擎运行，不需要 HUD/暂停/退出确认。用普通 Scene + 自绘返回按钮。
6. **BombIslandBattleScene 的 ResultOverlay「下一关」**：胜时显示，败时隐藏。onNext 创建新 `BombIslandBattleScene(levelIdx+1, engine.getUnlocked())`。

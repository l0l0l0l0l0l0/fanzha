## Layer 2：扩展 Particle + 四引擎注入 juice

### 2.1 扩展 `src/engine/Particle.ts`

当前 `ParticleSystem` 仅支持圆点粒子（`arc` + `lighter`）。扩展为多形态，**保持 API 向后兼容**（现有 `spawn()` 调用不受影响）。

**新增粒子类型**（通过 `spawn(opts.type)` 选择）：
- `"dot"`（默认，现有行为）
- `"ring"`：扩散光环，半径随生命增长、alpha 衰减，`stroke` 而非 `fill`
- `"spark"`：线段粒子，带旋转角，长度随速度衰减（模拟碎片飞溅）
- `"debris"`：小矩形，带旋转 + 重力（爆炸碎片）

**接口扩展**：
```ts
spawn(opts: {
  x, y, count?, speed?, life?, size?, color, gravity?, spread?,
  type?: "dot" | "ring" | "spark" | "debris",  // 新增，默认 "dot"
  angle?: number,                               // spark/debris 初始朝向
  ringWidth?: number,                           // ring 描边宽度
  friction?: number,                            // 阻力系数（默认 0.97）
}): void
```

**新增便捷方法**：
```ts
spawnBurst(x, y, color, opts?): void  // 综合 burst：ring + sparks + dots
```

实现要点：
- `P` 接口扩展 `type`、`angle`、`rot`（旋转）、`vrot`（角速度）、`ringW`
- `render(ctx)` 内按 `type` 分支绘制，全部沿用 `globalCompositeOperation = "lighter"`
- ring 用 `ctx.arc + stroke`，半径 = `size + (1-life/maxLife) * size * 3`
- spark 用 `ctx.moveTo/lineTo`，长度 = `size * 2 * alpha`
- debris 用 `ctx.save/translate/rotate/fillRect/restore`

### 2.2 四引擎注入点（已逐文件核实行号）

## Layer 3：Hub/场景/结算动效打磨

### 3.1 移除冗余 `drawScanlineOverlay` 调用
PostFX 已在 SceneDirector 全局层绘制 CRT 扫描线，以下三处 per-scene 调用会导致双重扫描线，删除：
- `src/scenes/HubScene.ts` L57：`drawScanlineOverlay(ctx, screenW, screenH);` → 删除
- `src/scenes/GameShellScene.ts` L38：`drawScanlineOverlay(ctx, screenW, screenH);` → 删除
- `src/scenes/BriefingScene.ts` L222：`drawScanlineOverlay(ctx, screenW, screenH);` → 删除

（`drawScanlineOverlay` 函数本身保留在 widgets.ts，不删除——未来可能单场景需要。）

### 3.2 HubScene 动效增强
文件：`src/scenes/HubScene.ts`

- **Hero 标题霓虹脉冲**（L110-125）：把固定 `shadowBlur: 16` 改为 `16 + Math.sin(this.t * 2) * 6`，让「游戏」二字呼吸闪烁。需在类里加 `private t = 0;` 并在 `update(dt)` 里 `this.t += dt`。
- **环境粒子**：在 HubScene 持有一个 `ParticleSystem`，每帧在屏幕底部随机 spawn 1-2 个 cyan 上升粒子（`vy = -20`，`life = 3`），模拟数据流。`render` 末尾 `particles.render(ctx)`。
- **卡片 hover 霓虹边**：`renderGameCard` 中 `pressedButton === card-${i}` 时，给 `drawPanel` 的 borderColor 加 `shadowBlur` 脉冲 + 四角括号（复用 PostFX 的 corner bracket 思路，但画在卡片局部）。
- **数字滚动**：`drawStatCard` 的 value 用滚动动画——需在 HubScene 维护 `displayedValues` 对象，每帧 lerp 向真实值。**简化方案**：直接在 widgets.ts 加 `drawNumberRollup(ctx, x, y, current, target, color)`，HubScene 维护 current 值数组。

### 3.3 BriefingScene 入场动效
文件：`src/scenes/BriefingScene.ts`

- 利用 Scene 基类的 `enterT`（0→1 入场进度），在 `render` 开头：
  - 整体 `ctx.globalAlpha = enterT`
  - 面板 `py` 加 `40 * (1 - enterT)` 上移淡入
  - 图标框 `shadowBlur` 随 enterT 从 0 到 12
- 倒计时最后 1 秒（`countdown <= 1`）：`postFX.flash(warn, 0.15)` 每秒触发一次（在 `update` 里 countdown 减到 1 时触发）。

### 3.4 ResultOverlay 结算动效
文件：`src/scenes/ResultOverlay.ts`

- **分数滚动**：维护 `displayedScore = 0`，每帧 lerp 向 `result.score`（`displayedScore += (target - displayedScore) * 0.1`），渲染时显示 `Math.floor(displayedScore).toLocaleString()`。当差值 < 1 时锁定。
- **胜利撒花**：`result.win` 时，持有 `ParticleSystem`，在 `enterT > 0.5` 后每帧 spawn 2-3 个 confetti（多彩 debris + gravity）从卡片顶部洒落。
- **失败 glitch**：`!result.win` 时，enterT 到 0.3 触发一次 `postFX.glitch(0.6)` + `postFX.flash("#E5353B", 0.3)`。
- **标题脉冲**：标题 shadowBlur 随 `pulse` 呼吸（已有 `this.pulse`）。

### 3.5 GameShellScene 顶部警灯条
文件：`src/scenes/GameShellScene.ts`

- `renderTopBar` 顶部加一条 2px 红蓝交替脉冲条（复用 PostFX neonFrame 的 police 脉冲逻辑），强化「警务终端」感。
- 用 `this.t`（需新增）+ `Math.sin` 做 0.5Hz 红蓝交替。

## 假设与决策

- **不改玩法**：所有注入仅在事件回调内加视觉触发，不改状态机、不改分数、不改碰撞。
- **不改 createCanvas 单例**：维持 Layer 1 的零 buffer 决策，postFX 全屏级、粒子引擎画布级，互不干扰。
- **不删 drawScanlineOverlay 函数**：仅删调用点，函数保留备用。
- **enterT 复用**：Scene 基类已有 `enterT`（ResultOverlay L56 已用），BriefingScene 直接用。
- **postFX 触发不依赖引擎画布**：postFX 作用在 SceneDirector.displayCanvas，引擎内 import 后直接调 `postFX.flash(...)` 即可，无需传 ctx。
